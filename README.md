# BTC 五分钟涨跌交易工作台

面向币安 App「合约 → 涨/跌 → BTC 5分钟内涨或跌」，使用官方 Prediction Trading REST API。支持手动报价与下单、自定义规则、可信本地代码策略和 jev 决策。默认显示币安 BTCUSDT 真实现货行情；目标价只从官方预测市场接口读取，未配置凭证时留白；预测盘口与资金交易为模拟。真实 BTC 行情无需 API Key，约每 2.5 秒轮询一次。

## 启动

需要 Node.js 22 或更高版本，无第三方运行依赖。

```bash
npm start
```

访问 http://127.0.0.1:4317 。`npm run dev` 启用后端文件变化自动重启，重启会停止自动策略。

## 一期：手动操作

1. 查看场次、目标价、参考价、盘口和剩余时间。
2. 选择买涨或买跌，设置金额、含费用价格上限及滑点。
3. 获取报价，核对份额与费用后确认提交。
4. 在订单区查看成交状态和持仓。演示环境的限价单只模拟立即成交，不模拟挂单排队。

设置 `BTC_PRICE_MODE=simulated` 并重启可使用纯模拟行情；此时演示场景按钮可切换至剩余 25 秒、价差 ±50 USD 的新模拟场次。模拟初始余额 1000 USDT，模拟费用 2%；换期使用上一期最后采样价结算，仅验证功能，不代表真实成交或策略收益。演示与真实订单分开显示。

## 接入真实账户

复制 `.env.example` 为 `.env`，在本地编辑，勿把密钥放进浏览器或聊天。`.env` 已加入忽略规则。

```bash
cp .env.example .env
```

设置 `MODE=live`、`BINANCE_API_KEY`、`BINANCE_API_SECRET`。当前实现 HMAC-SHA256 API Key；RSA / Ed25519 Key 尚未支持。按币安要求开通预测账户、SAS 和 Prediction Trading 权限。多钱包时填写 `BINANCE_WALLET_ADDRESS`，钱包 ID 会从所属账户查询并核对。

先保持 `LIVE_TRADING_ENABLED=false`，重启后进行只读核对：

- 当前场次确为 BTCUSDT、CRYPTO_UP_DOWN，持续时间精确为 300000 毫秒。
- API 目标价、结束时间、两个方向与 App 一致。
- 当前产品规则、价格来源、平局处理及停止接单时间已核实。
- 资金来源、账户余额及费用口径已核实。

本版本使用币安 BTCUSDT 现货 REST 报价作为参考行情，响应未提供成交时间，界面显示接收时间。**仅当该产品的结算价格确认为此价格源时**，才能配置 `SETTLEMENT_PRICE_SOURCE=BINANCE_SPOT` 与 `MARKET_RULES_VERIFIED=true`；若采用指数、预言机或 TWAP，须先实现对应价格适配器，不能用现货替代。未满足条件时真实下单受阻。

准备真实交易时设置 `LIVE_TRADING_ENABLED=true` 并重启。自动交易开关每次启动均关闭，需要在面板中手动开启。`FUNDING_SOURCE=MPC/CEX` 决定扣款来源；`ACCOUNT_TYPE=SPOT/FUNDING` 是参考／结算账户，二者含义不同，不自动转账。面板显示的是预测钱包余额，不能作为 CEX 可用余额。

未配置实际账户，因此官方接口参数已按文档实现，但真实权限、签名兼容性、费用口径、场次及真实成交均仍需账户联调；不能据模拟验收认为实盘已验证。

## 自定义规则与代码

在「交易策略」配置结束前窗口、最晚提交余量、绝对价差、买入价上限、金额、方向及每期最多次数。正价差只买涨，负价差只买跌；不会只凭绝对差值猜方向。自动策略始终重新校验场次、时效与价格。

编辑 `strategies/custom.mjs` 并启用「自定义代码」：

```js
export function decide(ctx) {
  if (ctx.btc.changes['5s'] === null) return { action: 'SKIP', reason: '短线数据不足' };
  return { action: ctx.btc.deltaUsd > 0 ? 'BUY_UP' : 'BUY_DOWN', reason: '自定义判断通过' };
}
```

`ctx` 提供 market、timing、btc（价差、5/15/30/60 秒变化、60 秒范围）、outcomes（两侧盘口）、strategy 和 risk。返回 `BUY_UP` / `BUY_DOWN` / `SKIP`。每次在独立 Worker 执行，500ms 超时，Worker 环境不传递密钥。它是**可信本地代码扩展，不是安全沙箱**，请只使用自己信任的代码。执行器始终控制下单，代码不能绕过基础交易限制。

## 二期：jev

使用已有 jev CLI，不将 CLI 作为 npm 依赖安装。在本机终端完成授权：

```bash
jev auth set
jev auth check
```

如果不在 PATH 中，将 `.env` 的 `JEV_COMMAND` 设置为可执行脚本绝对路径。`strategies/jev.json` 定义动作判断，`JEV_TIMEOUT_MS` 和 `JEV_MIN_CONFIDENCE` 设置超时与判断阈值。在面板将决策方式改为「规则通过后交给 jev」。

程序先筛选规则，计算时间与行情指标，再向 jev 发送必要快照；不发送币安密钥、钱包签名或原始账户资料。jev 只返回判断，低置信度、超时、缺少配置、方向冲突或行情变化均跳过。自动运行最多每两秒一次 jev 判断。**判断置信度不是涨跌胜率**，需要用记录与真实结算结果评估。本机已检测到 jev CLI 和 TypeSafe 本地凭证配置；仅检查了配置状态，未进行真实模型请求、凭证有效性或交易判断表现验证。

## 订单保护与记录

- 单笔和当日（Asia/Shanghai）额度；金额最多六位小数，接口金额用 BigInt 转换为 18 位单位。
- 手动每期最多一笔，自动按策略配置次数。包含提交中与结果未知订单的占用，拒绝重复报价和重复确认。
- 保守按买入金额加 `feeAmount` 计费，最少接收份额对应的含费用价格也必须小于上限。实际费用含义需联调核对。
- 报价有效期最长本地 10 秒；旧场次、过期行情及尾部禁止提交窗口不能下单。
- 请求前持久化订单，真实下单不自动重试。超时或异常标记 UNKNOWN，停止自动交易并阻止后续交易。
- 在订单区「核对」输入币安订单 ID 关联实际订单；确认确实未下单时可留空并输入确认文字解除占用。谨慎核对，不能把未查到立即等同失败。
- `data/state.json` 保存订单与策略，`data/events.jsonl` 保存交易与决策快照。文件损坏时停止启动，不默默清空。
- 仅监听本机 127.0.0.1，校验 Host、Origin 与会话 token，页面不展示密钥。

额度账本以本工具订单为基础，当前同场次已有账户持仓也会参与阻止重复交易。**不完整覆盖你在 App 或其他工具中发生的当日交易**，实盘运行时应避免并行交易；完整跨工具额度需要后续接入账户全量成交统计。盘口目前使用 REST 轮询，尚未实现预测市场 WebSocket，因此不适合争抢最后一两秒机会。

## BTC 真实行情

默认 `BTC_PRICE_MODE=live`，调用币安公开 `GET /api/v3/ticker/price?symbol=BTCUSDT`，不需要账户密钥。页面标记真实现货来源与接收时间；断网保留上次价格并明确报错，不回退到随机模拟价格。目标价通过官方市场列表定位当前 BTC 五分钟场次，再读取市场详情的 `variantData.startPrice`；不使用首次采样价、现货 K线开盘价或上一期目标价替代。即使 `MODE=demo`，填写 API 凭证也能只读查询真实目标价，无需开启下单。没有凭证、场次过期或字段缺失时目标价、价差与真实场次倒计时留白，并禁止依赖目标价的交易和自动策略。预测市场盘口仍需完整账户接入。

## 尾盘模拟交易

「模拟交易」为独立菜单，使用真实 BTC 参考价、真实目标价和真实预测盘口，支持设置入场窗口、最小绝对价差与每次下注金额；默认最后 **10 秒**、价差 **0 USD**、金额 **1 USDT**，每期最多尝试一次，不调用真实报价或下单接口。当前参考价高于目标价选择涨，低于目标价选择跌，价差未达阈值或相等则在窗口内继续等待。默认启用，页面可随时停止；设置与开关持久化，重启后按保存的状态继续。

默认模拟 500ms 执行延迟，之后重新查询该方向卖盘。最高报价默认 0.99，滑点容忍以百分比输入，默认 10%（内部1000基点）。无卖盘、涨停到 1、报价超限、盘口过期、深度不足、请求失败、换期或已经进入最后 1 秒时记录失败；按 FOK 整笔成交模型计算，不把部分成交或信号触发当作成功。设置的下注金额为模拟买入本金，费用按 Predict 官方 Taker 公式逐档估算：`feeRateBps / 10000 × min(成交价格, 1 − 成交价格) × 成交份额`，各档汇总，费用另计，不假设账户折扣，净盈亏扣除该费用；没有模拟未知网络费或真实撮合排队，不能把模拟成交视为真实订单保证。

结束后查询原场次官方 `endPrice` 与 RESOLVED 状态，核对胜负标志后结算；平局每份按 0.5 兑付。官方结果尚未发布时保持待结算，每 10 秒重试，不使用现货最后一笔价格猜结果。判断价来自币安现货，官方结算价来自 Chainlink，记录保存该差异，模拟收益不代表已经实现同源行情策略。

每次决策和执行状态保存在 `data/state.json`；本期结束后生成 `data/paper-trades/round-场次ID.json`，未成交、跳过、待结算也会写文件，官方结果到达后更新同一文件。页面提供全量 JSON 导出，展示最近 300 条，可筛选已结算、未成交、待处理、赚钱、赔钱。旧演示订单不混入本次模拟统计。

统计分别计算成交率（成交 / 已完成下注尝试）、成功率即已结算胜率（方向正确 / 已结算成交）、赚钱/赔钱/持平笔数、盈利金额、亏损金额、净盈亏、失败、跳过、待处理和平局。未成交不计亏损，未结算不计胜率；猜对方向也可能因高价和费用造成亏损。

模拟日志同时输出到启动服务的终端和浏览器开发者工具 Console，前缀为 `[模拟交易]`。买入判断和执行日志包含场次、上海时间、买涨/买跌、参考价、目标价、盘口报价或成交均价及状态。期末日志包含成功/失败/平局、盈利金额、亏损金额、净盈亏和估算费用；未成交盈亏为零，已成交等待官方结果发布后打印。日志随记录保存；浏览器刷新会回放最近记录已有日志，同一页面轮询不会重复打印。

在「模拟交易 → 模拟状态」设置最后多少秒入场（2～300）、最小绝对价差（0～1000000 USD）和每次下注金额（0.01～1000 USDT），点击保存。三项留空采用默认值10、0、1。价差以未截断的参考价和目标价计算，达到阈值（含等于）才尝试；最后1秒禁止执行。配置保存后立即影响尚未尝试的场次，已有待执行或成交记录使用其判断时配置，历史记录不改变。

手续费模型为 `PREDICT_FUN_TAKER_V1`，适用于模拟市场吃单。官方说明：https://docs.predict.fun/the-basics/predict-fees-and-limits 。已有模拟成交记录启动时按保存的各档成交重算，原费用及盈亏保存在 `previousFeeCalculation`，独立文件和统计同步更新；未成交不扣费。手续费及模拟盈亏最多显示8位小数，BTC价格仍截断2位。实际交易费用以官方报价/成交数据为准，模拟不假设折扣或网络费。

### 兜底与审查
模拟设置可启用兜底，填写兜底入场秒数和最小绝对价差。兜底秒数必须小于主策略窗口；主策略持续优先检查，主策略尚未触发且已进入兜底窗口时再检查兜底。每期最多尝试一次，买入失败不再用兜底重试。两策略均不满足时不交易，期末保存跳过记录。
进入主策略窗口和兜底窗口时分别打印一次console，无论是否达到价差；按第一次检测到剩余时间不大于设置秒数触发，轮询不保证精确到整秒。窗口日志保存并可在刷新时回放。记录新增价差、判断时设置（窗口、价差、本金、上限、滑点、延迟）、兜底是否触发及具体兜底条件，历史无兜底配置视为未启用。

模拟设置的滑点单位为百分比，支持0～100%，最多两位小数，留空默认10%。例如输入10表示10%，内部换算为1000bps用于盘口执行上限。历史记录显示原实际滑点的百分比，不修改历史交易参数。

模拟交易记录支持分页，默认每页10条，可选20或50条，支持上一页、下一页及页码跳转。筛选或改变每页条数回到第一页，自动刷新保留当前页并校正越界页码。分页范围为最近300条，完整历史仍可导出JSON。

模拟交易页的「归零」按钮清除模拟记录、统计、窗口日志和 `data/paper-trades/` 场次文件，保留设置及启动/停止状态。正在执行的模拟操作完成后统一清除，避免响应返回后重新写入。当前场次归零后不再下注，已开启时下一期恢复检查。归零状态持久化，刷新或重启不会恢复旧记录。已有下载文件和外部Console输出不会被删除。

### 最后90秒触达0.98挂单策略
「模拟策略」可选择尾盘价差或0.98限价挂单。后者在结束前90秒至1秒内，单一方向新鲜有效卖一价达到或超过0.98时，跟随该方向挂限价0.98的模拟买单，每期最多一单。两方向同时触达则等待，不依赖BTC价差或兜底条件。金额和模拟延迟沿用设置，固定限价0.98不受滑点放宽影响。
挂单每秒重新检查真实卖盘，只有价格不高于0.98且深度足够整笔买入才模拟成交，可获得更低的价格；涨停、无卖盘或深度不足继续等待，最后1秒撤销。停止和归零可取消模拟挂单，重启保留订单，不重复挂单。记录区区分挂单待成交、成交待结算及到期撤销。
本实现为保守的盘口穿价整笔成交模拟，不模拟Maker队列位置、部分成交及真实撮合。费用沿用官方Taker公式作为保守估计，不承诺挂单为Maker免手续费；真实挂单费用以实际撮合角色为准。

### 限时触达参数
策略名称改为「限时触达」，可设置触达窗口（2～300整数秒，默认90）和触达价格（0.01～0.99，每份USDT，最多两位小数，默认0.98）。窗口内有效卖一价达到或超过触达价格即挂同价限价单；价格参数同时控制触发阈值和挂单上限，成交可获得更低价格。留空保存恢复各自默认值。切回价差策略保留触达设置，历史及已挂订单保留判断时参数，修改只影响尚未挂单的场次。

公共BTC行情和服务器时间使用币安官方行情专用域名 `data-api.binance.vision`，无需密钥；预测场次、盘口和账户仍通过原官方SAPI接口请求。预测接口中断时，参考价及图表独立更新，目标价留空、盘口关闭、模拟触发暂停，不用替代数据生成场次或目标价。账户权限错误与公共行情网络错误独立显示。

BTC公共行情使用独立刷新任务（默认2.5秒），不会等待预测接口超时后才刷新。网络请求本身仍可能延迟，页面显示的秒数是数据年龄。
