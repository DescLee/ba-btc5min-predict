限时触达策略：在设置的窗口内，有效卖一价达到或超过触达价格后，按该价格挂限价单。每期最多一单，不使用价差及兜底；价格过高或深度不足继续等待，最后1秒撤销。仅模拟盘口穿价整笔成交，未模拟挂单排队，费用保守按Taker估算。

兜底秒数必须小于主策略秒数。主策略未触发时才检查兜底；金额与执行限制沿用主设置。主策略已尝试但买入失败时，不重复下注。

成交与统计口径

  • 进入设置的入场窗口后，绝对价差达到阈值才尝试下注；未达标则继续等待，高于目标价买涨、低于买跌，相等不下注。
  • 模拟延迟后重新查询真实卖盘；无卖盘、报价达到 1、价格超限或深度不足均记为未成交。
  • 在触达窗口内，单一方向卖一价达到设置价格后按该价格挂限价单；价格超限或深度不足继续等待，最后1秒撤销未成交挂单。
  • 采用 FOK 整笔成交模型，不把部分深度当作成功；最后 1 秒停止执行。
  • 结束后轮询官方 endPrice 与结算结果，结果未发布时保持待结算。
  • 成交率 = 成交笔数 ÷ 已完成的下注尝试；跳过和执行中不计入分母。
  • 胜率 = 方向正确的笔数 ÷ 已结算成交笔数；未成交和待结算不计入。
  • 赚钱／赔钱按扣除估算费用后的净盈亏判断，猜对方向也可能亏损。

方向判断使用当前币安现货参考价，实际结算来源为 Chainlink；保留价源差异，不把现货当作结算价。费用按场次费率估算；下注金额为模拟本金，费用另计，不代表真实交易所接受该金额的市价订单。

期后记录文件：data/paper-trades/round-场次ID.json。执行中的状态同步保存在 data/state.json，刷新或重启不会重复下注。

入场条件与执行

BTC · 5分钟

自定义代码在基础条件通过后运行，不能绕过额度、价格、时效或方向限制。

策略执行流程

  1. 等待入场窗口

    例如结束前 30 秒至 5 秒，留出接口执行时间。

  2. 检查价格与额度

    价差、盘口、买入成本、数据时效和每期次数须全部满足。

  3. 运行你的判断

    可选自定义代码和 jev；超时、缺失或低置信度均跳过。

  4. 获取报价并再次核对

    条件变化或场次切换就丢弃判断，不沿用旧结果。

  5. 下单与记录

    记录决策快照、报价和订单状态，支持后续复盘。

自定义代码

编辑项目内 strategies/custom.mjs，导出 decide(ctx)，返回 BUY_UP、BUY_DOWN 或 SKIP。

jev 接入

在本机完成 jev 授权，并配置 JEV_COMMAND。判断置信度不能当作交易胜率；未配置时跳过，决策输入与结果写入本地日志。

本地配置步骤

  1. 复制 .env.example 为 .env。
  2. 填写币安 API Key / Secret，开启 Prediction Trading 权限并完成预测账户与 SAS 授权。
  3. 设置 MODE=live，保持真实下单开关关闭，重启后先核对真实行情。
  4. 确认规则与价格源后配置验证项；准备交易时再开启真实下单开关。

无需将密钥填写到聊天或浏览器。多钱包账户需显式选择钱包。当前仅支持已核实为 BINANCE BTCUSDT 现货价格源的真实交易；其他价格源会阻止下单。

接入验收清单

  • API 场次是 BTC，持续时间恰为 300 秒。
  • 目标价、到期时间与 App 一致。
  • 涨跌方向的 token 映射明确。
  • 盘口、资金来源和费用口径一致。
  • 结算规则与程序使用的价格源一致。
  • 真实订单结果可在币安账户中核对。
